# AetherSync

**Physics doesn’t wait. Neither should your game.**

AetherSync is middleware that brings quantum-inspired tensor mathematics to real-time multiplayer synchronization. It delivers physically accurate, self-correcting audio and visual event propagation with extremely low effective latency.

## Features
- Real physics-based propagation (speed of sound, attenuation, occlusion)
- Adaptive self-correcting latency compensation
- Quantum-inspired tensor methods for superior scaling
- Hardware accelerated (CPU/GPU/TPU)
- Engine agnostic (Unity, Unreal, custom)
- Lightweight core with optional heavy acceleration

## Quick Start
```bash
git clone https://github.com/jabrahns-source/aethersync
cd aethersync
./build.sh
python3 run_engine.py
```
